# Python Programming Projects

This repository contains four Python projects completed during a Python programming internship. Each project focuses on a different programming concept and helps improve practical Python skills.

## Projects

### 1. Hangman Game
A simple word guessing game where the player tries to identify a hidden word by guessing letters within a limited number of attempts.

### 2. Stock Portfolio Tracker
A Python program that calculates the value of selected stocks based on their prices and quantities entered by the user.

### 3. Task Automation
A simple automation program that organizes JPG files by moving them from one folder to another automatically.

### 4. Basic Chatbot
A beginner-friendly chatbot that gives predefined responses to common user messages.
